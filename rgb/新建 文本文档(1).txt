# Dual-RGB Stereo → FoundationStereo → 6D Pose

**双 RGB 立体标定与深度生成流程（中 / 德）**

---

## 1. 项目概述 / Projektübersicht

**中文说明：**
本项目使用两台 RGB 相机（如 Intel RealSense D435 的 RGB 模块）构建双目立体系统，通过棋盘格完成标定与立体矫正，并将矫正后的左右图像输入 **FoundationStereo (FS)** 生成深度图，最终用于下游的 **6D Pose Estimation（如 FoundationPose / SERP-6D）**。

**Deutsch:**
Dieses Projekt verwendet zwei RGB-Kameras (z. B. RGB-Sensoren der Intel RealSense D435), um ein Stereo-System aufzubauen.
Nach Schachbrett-Kalibrierung und Stereo-Rektifizierung werden die rektifizierten Bilder in **FoundationStereo (FS)** eingespeist, um Tiefenkarten zu erzeugen, die anschließend für **6D-Posenschätzung** (z. B. FoundationPose / SERP-6D) genutzt werden.

---

## 2. 总体流程 / Gesamtpipeline

```
双 RGB 图像采集
   ↓
棋盘格标定（单目 + 双目）
   ↓
stereo_calib_rgb.npz
   ↓
立体矫正（Rectification）
   ↓
生成 FS 所需内参（K + baseline）
   ↓
FoundationStereo 深度
   ↓
6D Pose Estimation
```

---

## 3. 文件与脚本说明 / Dateien & Skripte

### 3.1 标定图片采集

**save_calib_images_dual_rgb_bilingual.py**

**中文：**

* 从两台 RGB 相机采集棋盘格图像
* 保存为：

  ```
  stereo_calib_images_rgb/
    ├─ left_000.png
    ├─ right_000.png
    ├─ left_001.png
    └─ right_001.png
  ```
* 建议拍摄 **15–25 组**，覆盖不同位置、角度和距离

**Deutsch:**

* Aufnahme von Schachbrett-Kalibrierbildern aus zwei RGB-Kameras
* Empfohlen: **15–25 Bildpaare** mit guter räumlicher Abdeckung

⚠ **注意 / Achtung：**

* 左右相机的 **SERIAL 定义必须在所有脚本中保持一致**
* 标定和运行时 **分辨率必须完全一致**

---

### 3.2 双目立体标定

**stereo_calibrate_rgb_bilingual.py**

**中文：**

* 先进行左右单目标定
* 再进行双目标定（固定单目内参）
* 最后执行 `cv2.stereoRectify`
* 输出统一的：

  ```
  stereo_calib_rgb.npz
  ```

包含：

* 内参 `K_left / K_right`
* 畸变 `dist_left / dist_right`
* 外参 `R / T`
* 矫正矩阵 `R1 / R2`
* 投影矩阵 `P1 / P2`
* 视差-深度矩阵 `Q`

**Deutsch:**

* Zuerst Monokamera-Kalibrierung
* Danach Stereo-Kalibrierung mit fixierten Intrinsics
* Anschließend Stereo-Rektifizierung
* Alle relevanten Parameter werden in `stereo_calib_rgb.npz` gespeichert

⚠ **关键点 / Wichtig：**

* 当前使用 `alpha = 0`（最紧裁剪）

  * 对 Pose 稳定性要求高时，可考虑 `alpha = -1` 或 `0.5`

---

### 3.3 生成 FoundationStereo 内参

**make_fs_intrinsic_from_npz_bilingual.py**

**中文：**

* 从 `stereo_calib_rgb.npz` 中读取 **矫正后的投影矩阵**
* 使用：

  * `K = P1[:,:3]`
  * `baseline = -P2[0,3] / P2[0,0]`
* 输出 FS 使用的内参文件：

  ```
  K_d435_2RGB.txt
  ```

**Deutsch:**

* FS-Intrinsics werden aus den **rektifizierten Projektionsmatrizen** abgeleitet
* Baseline wird aus `P2` berechnet (nicht aus rohem T-Vektor)
* Dadurch sind **K, Baseline und rektifizierte Bilder im selben Koordinatensystem**

⚠ **非常重要 / Sehr wichtig：**

* **不要**使用 `||T||` 作为 baseline
* 否则深度尺度会错误，直接导致 6D Pose 偏移

---

### 3.4 运行时立体矫正并输出 FS 输入

**capture_rectified_for_fs_bilingual.py**

**中文：**

* 运行时采集左右 RGB
* 使用 `stereo_calib_rgb.npz` 做：

  * 去畸变
  * 立体矫正
* 输出：

  ```
  shared_fs_test/
    ├─ left_rect.png
    └─ right_rect.png
  ```

**Deutsch:**

* Laufzeitaufnahme beider RGB-Streams
* Entzerrung + Rektifizierung mit derselben Kalibrierdatei
* Ausgabe rektifizierter Bilder für FoundationStereo

⚠ **调试建议 / Debug-Hinweis：**

* 同时保存 `left_raw.png / right_raw.png`
* 用于检查：

  * 左右是否颠倒
  * 曝光/亮度差异
  * 是否存在明显不同步

## 4. 与 6D Pose 精度强相关的注意事项

## Wichtige Hinweise für genaue 6D-Posen

### 4.1 不同步（已知问题）

* 双 RGB 无硬件同步
* 运动物体或手持拍摄时会明显影响深度

### 4.2 自动曝光 / 白平衡（**强烈建议关闭**）

* 左右相机各自自动调节
* 会降低 stereo 匹配质量
* 深度噪声 ↑ → Pose 抖动 ↑

### 4.3 K / baseline / 图像必须完全匹配

* **rectified 图像**
* **K_d435_2RGB.txt**
* **深度图**
* **Pose 使用的相机模型**

👉 任意 resize / crop / pad 都必须同步更新 K

### 4.4 左右定义错误的典型症状

* 深度“看起来有”，但：

  * pose 整体偏
  * 方向反
  * 框对不上物体

---

## 5. 推荐最小验证流程 / Empfohlene Minimaltests

1. **棋盘格 rectified 验证**

   * 同一角点在左右图中应几乎位于同一 y 坐标

2. **已知距离物体验证深度尺度**

   * 用尺子/标定板
   * 验证 FS 深度是否符合真实距离

3. **静态场景下 Pose 稳定性测试**

   * 若静态仍抖动 → 通常是 K / 深度质量问题

---

## 6. 总结 / Zusammenfassung

**中文：**
该 RGB-Stereo 流程在几何上是正确的，但对一致性和标定质量非常敏感。
只要 **rectified 图像 + K + baseline + depth** 保持同一坐标体系，并避免自动曝光和裁剪带来的副作用，就可以获得可用于 6D Pose 的稳定深度。

**Deutsch:**
Die Pipeline ist geometrisch korrekt, jedoch sehr sensitiv gegenüber Inkonsistenzen.
Wenn **rektifizierte Bilder, K, Baseline und Tiefe** strikt konsistent sind, kann FoundationStereo zuverlässige Tiefen für 6D-Posenschätzung liefern.
